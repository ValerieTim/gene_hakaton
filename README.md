# Прототип системы определения эволюционного происхождения бактериальных генов

## Идея проекта
Система анализирует геномы пяти бактерий (*E. coli*, *E. fergusonii*, *S. flexneri*, *S. enterica*, *P. aeruginosa*), чтобы определить наиболее вероятный сценарий происхождения гена: вертикальное наследование, дупликация или горизонтальный перенос (HGT).

## Инструменты
- **DIAMOND** — поиск белковых гомологов.
- **Python (Biopython, Pandas)** — обработка FASTA/GFF и анализ данных.
- **Сравнительная геномика** — анализ синтении и GC-состава.

## Структура проекта
- `scripts/` — код пайплайна.
- `results/` — выходные данные и итоговый отчет.

## Результаты
Система проанализировала 23 004 белка и выявила три контрольных сценария. Подробный отчет с уликами и выводами находится в файле `results/final_report.md`.
